# Third-party dependencies

- JUCE 9.0.4 is fetched from the official juce-framework/JUCE repository and pinned to its 9.0.4 tag by CMake FetchContent. JUCE framework licensing applies. Review the current JUCE 9 licence at https://juce.com/legal/juce-9-licence/ before distributing binaries or source.
- CMake 3.22 or newer and Apple Xcode are used for macOS builds.
- Git LFS stores the original WAV and MP3 files and is installed from Homebrew.

No paid dependency is required for this prototype. JUCE splash-screen and licensing-related behavior is not disabled by this project.
